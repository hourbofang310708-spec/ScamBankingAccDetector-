This script generates a synthetic text classification dataset designed to train and benchmark NLP models for targeted financial fraud and phishing detection. Moving beyond rigid template matching, it uses a modular, combinatorial text engine to synthesize realistic banking notifications (Ham) and adversarial social engineering attacks (Spam). To accurately mimic real-world production conditions, the generator incorporates statistical log-normal distributions for financial transactions, enforces class-imbalance configurations, and injects structural human noise—such as typos, casing anomalies, and localized formatting variations—ensuring the resulting models develop robust semantic boundaries rather than over-indexing on perfect string patterns.
